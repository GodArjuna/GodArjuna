## Dicas para Uso

### Personalização

Sempre substitua:
- [NOME] → Nome do cliente
- [ID] → ID do pedido
- [SABOR] → Sabor do pudim
- [VALOR] → Valor monetário
- [DATA] → Data formatada
- etc.

### Tom de Voz

Mantenha:
- ✅ Amigável e próximo
- ✅ Profissional
- ✅ Entusiasta (emojis moderados)
- ✅ Claro e objetivo

### Emojis

Use com moderação:
- 🍮 Pudim
- 🎉 Celebração
- ⚠️ Alerta
- ✅ Confirmação
- 💰 Dinheiro/Preço
- 📦 Pedido
- ⭐ Avaliação

### Adaptação

Sinta-se livre para:
- Ajustar o tom conforme seu público
- Adicionar sua personalidade
- Usar linguagem regional
- Testar variações

## Testes A/B

Experimente diferentes versões:

**Versão A (Formal):**
```
Olá [NOME], seu pedido foi confirmado.
Detalhes: [...]
```

**Versão B (Informal):**
```
Oi [NOME]! 🎉 Pedido confirmado!
Bora ver os detalhes: [...]
```

Meça qual tem melhor engajamento!
