# Guia Rápido de Início 🚀

## Para Quem Está Com Pressa

**5 passos para começar em 30 minutos:**

### 1️⃣ Criar Conta n8n (5 min)
- Acesse [n8n.cloud](https://n8n.cloud)
- Cadastre-se gratuitamente
- ✅ Pronto!

### 2️⃣ Configurar Google Sheets (10 min)
- Crie planilha "Gestão Pudins"
- Copie estrutura de [planilhas-templates](examples/planilhas-templates/README.md)
- Conecte no n8n (Credentials → Google)

### 3️⃣ Criar Formulário (5 min)
- Google Forms: "Pedido de Pudim"
- Vincule com planilha
- Copie link para compartilhar

### 4️⃣ Configurar Notificações (5 min)
**Opção A - Telegram (mais fácil):**
- Procure @BotFather no Telegram
- `/newbot` → siga instruções
- Conecte bot no n8n

**Opção B - Email:**
- Use sua conta Gmail
- Conecte no n8n

### 5️⃣ Primeiro Workflow (5 min)
- Importe workflow básico
- Configure credenciais
- Teste com pedido fake
- Ative!
